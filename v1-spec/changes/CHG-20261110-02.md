### 2.3 规格回写：AC-79 的零分母规则

清理后 AC-79 的总体变成 0 条锚点。AC-79 原文只写「引用可回链率 100%」，
**没有定义分母为 0 时怎么判**——而 0/0 在数学上等于 1，会被读成 100% 通过。
这是规格写漏，不是代码缺陷，按派生链从验收标准这一层补：

> 本期总体为 0（无真实机构材料，未产生任何带锚点的问答或走查记录）时记
> 「不适用·未验证」，不得按 0/0 = 100% 计为通过，也不得据此放行 Q0。

这不是放宽判据：补之前 0/0 可以被解释成通过，补之后明确为不通过、不放行；
补之后，原本不通过的实现（60% 那次）依旧不通过。

## 4. 规格影响判定

> 这次改动会不会让一个本来通过 AC 的实现变成不通过，或让一个本来不通过的行为变成通过？

**只会让「本来不通过」保持不通过**。清理前 AC-79 是 3/5 = 60% 不通过；清理后总体为 0，
按新补的零分母规则记「不适用·未验证」，仍然不放行。补规则的方向是把 0/0 从「可能被读成
100%」改成「明确未验证」，属于收紧而非放宽。
