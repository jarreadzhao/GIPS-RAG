# CHG-20261110-18 前端工作台视觉体系对齐

| 项 | 内容 |
|---|---|
| 变更单号 | CHG-20261110-18 |
| 日期 | 2026-11-10 |
| 类型 | 前端呈现重构（无接口、无业务行为变化） |
| 发起 | 用户提出「参考另一个内部项目的前端页面，把当前前端做得和它类似」，确认口径为：全面对齐、深空默认 + 可切浅色、不要登录页、问答台改为工作台面板 |
| 影响文件 | `frontend/index.html`、`frontend/css/style.css`、`frontend/js/app.js`、`frontend/js/i18n.js`、`frontend/js/pages/chat.js`、`frontend/js/pages/search.js`、`frontend/js/pages/docs.js` |
| 版本结果 | PRD / 契约 / 接口 / 验收 均保持 v1.10，不变更 |

## 1. 变更缘由

当前前端只继承了参考项目的布局骨架（64px 侧栏 / 56px 顶栏 / 52px 页内条），但参考项目的组件体系没有带过来：

- 侧栏导航项是「图标 + 竖排文字」，且 `.nav-tip` 未定义样式，气泡被当作普通文字撑开；
- `brand-mark` 引用了未定义的 `--radius-sm`，圆角失效；
- 页内工具条高度占着，但没有页面传入 title / meta / actions，页面标题和操作全部挤在内容区；
- 缺少 badge、empty-state、seg、link-btn、table.tbl、page-title-row 等组件，按钮高度约 26px，与参考项目 34px 的密度不一致；
- 只有浅色主题；问答页仍是通用聊天气泡，与参考项目的工作台面板语言差距明显。

本次只改 `frontend/` 呈现层，不改 API 封装、QA 轮询、引用结构、语种切换与后端接口。

## 2. 规格影响

**无。** 本次不改变任何 R / CT / API / AC 的行为判据：

- R-49 的答案语种单一化规则未动，`answer_lang` 仍由界面语言决定；
- AC-79 / AC-80 / AC-83 的判定对象仍是「当前语种那一侧的引用」「答案不越界」「语种不混排」，只是引用卡片换了呈现方式；
- API-4 / API-5 / API-15 / API-19 的请求与响应字段未动。

因此四份规格不开新版本，不修改 `v1-spec/spec/` 下任何文件。

## 3. 代码处置

| 文件 | 改动 |
|---|---|
| `frontend/index.html` | 首屏前写入 `data-theme` 防闪白；顶栏新增 CONTEXT 上下文条、时钟、主题切换按钮；侧栏底部改为 RV 头像 + `reviewer / compliance` 文字 |
| `frontend/css/style.css` | 按参考项目重建设计系统：深空默认 + 浅色覆盖两套令牌；补齐 badge / seg / link-btn / empty-state / table.tbl / page-title-row / error-card 等组件；侧栏改为 208px「图标 + 文字」导航，窄屏收窄到 184px / 160px 仍保留文字（不再折叠成纯图标）；面板、按钮、表单、表格密度对齐参考项目；新增问答、检索、文档三页版式与窄屏适配 |
| `frontend/js/app.js` | `setPagebar` 支持 `{title, meta, actions}`；新增 `setContext` 上下文条与数组面包屑；新增主题初始化与切换（`localStorage` 持久化）；新增顶栏时钟；路由默认写入页面标题，页面可在 render 内覆盖；导航渲染补充 `.nav-label` 与禁用项标签 |
| `frontend/js/i18n.js` | 补齐外壳、问答、检索、文档三页的新文案键，中英双语；新增侧栏短品牌名 `brand.side`；`chat.count` 改为带 `{n}` 占位符 |
| `frontend/js/pages/chat.js` | 改为「左会话列表面板 + 右对话面板 + 底部输入面板」工作台结构；语种切换移入页内工具条；引用改为结构化卡片（条款号 / 页码 / 语种 badge + 等宽 char 区间与 hash）；空状态统一 `.empty-state` |
| `frontend/js/pages/search.js` | 增加页标题行、三段式通道开关（seg）与页内工具条结果计数；Top-5 条款卡片与原始候选表统一 `badge` / `table.tbl`；保留原有三通道请求与路由 `q` 参数 |
| `frontend/js/pages/docs.js` | 去掉 panel 嵌套，改为 `table.tbl` 只读清单；版本 / 页数 / 文本层 / 索引状态 / active 分列；刷新全部按钮移入页内工具条；沿用 `getDocument` 接口 |

## 4. 下游影响

- **契约**：无改动。请求头、字段、错误码均未变化。
- **接口**：无改动。`GET /provisions/search`、`POST /reviews`、`GET /reviews/{id}`、`GET /documents/{id}` 的调用方式与参数保持原样。
- **验收**：无改动。AC-79 / AC-80 / AC-83 的判据与阈值不变，前端仍按 `citations[].lang` 单语种渲染；语种切换仍走 `setLang` 整页重载。
- **codemap**：未新增模块，无需补行。

## 5. 验证

| 项 | 结果 |
|---|---|
| 静态门禁 | `spec_sync` / `spec_gate` / `spec_link` / `prd_lint` 全部通过（FAIL = 0） |
| 功能保持 | API 封装、QA 轮询终态判断、引用字段消费、语种切换、会话历史存储逻辑未改 |
| 主题 | 默认深空，切换写 `localStorage`，刷新后保持；首屏内联脚本避免闪白 |
| 浏览器实测 | 用无缓存参数强制重载，在 675px 视口验证：侧栏 160px、四个导航项图标与文字同行对齐、品牌区 GIPS 徽标 + Standards Console、底部 RV + reviewer/compliance、控制台无报错；问答页深色外壳、CONTEXT、时钟、主题按钮、页内语言切换均通过 |

## 6. 已知不覆盖

| 项 | 原因 |
|---|---|
| 1440px 及以上的大屏视觉 | 浏览器实测视口为 675px；大屏 208px 侧栏未逐屏截图比对，但断点规则已在 CSS 中覆盖 |
| 参考项目的登录页、命令面板、专注模式 | 用户已确认不要登录页；命令面板与专注模式对查询工具无实际收益，未引入 |
| 浅色主题逐页对比度 | 已按参考项目令牌取值，未做 WCAG 自动检查 |
| 英文长文案在 960px 以下的换行 | 已做基础窄屏适配，但未逐条检查英文页面标题与上下文条的换行效果 |
